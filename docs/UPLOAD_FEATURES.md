# SenseCraft AI 文件上传与管理功能

## 概述

SenseCraft AI 推理控制台现在支持完整的文件上传和管理功能，包括视频源和AI模型的上传、删除和重载。

## 新增功能

### 1. 视频源管理

#### 上传视频源
- 支持多种视频格式：MP4, AVI, MOV, MKV
- 支持批量上传
- 实时上传进度显示
- 自动文件类型验证

#### 视频源列表管理
- 显示所有已上传的视频源
- 支持删除视频源（除sample.mp4外）
- 实时刷新列表

### 2. AI模型管理

#### 上传AI模型
- 支持多种模型格式：PT, PTH, ONNX, ENGINE
- 支持批量上传
- 自动模型类型识别
- 上传后自动重载模型列表

#### 模型列表管理
- 显示所有可用模型
- 显示模型详细信息（名称、类型、任务等）
- 支持删除模型
- 支持模型重载

### 3. 用户界面改进

#### 智能模型切换
- 在视频流运行时更换模型会弹出确认对话框
- 用户可以选择立即应用新模型或取消操作
- 美观的自定义对话框，提供更好的用户体验
- 状态消息显示模型更换进度

#### 折叠式设计
- 上传和管理功能默认折叠，节省界面空间
- 点击标题栏可展开/折叠内容区域
- 提供"展开全部/折叠全部"切换按钮，一键控制所有功能区域
- 按钮文本会根据当前状态自动更新
- 折叠状态自动保存，下次访问时恢复

#### 上传区域
- 美观的拖拽式上传区域
- 文件类型提示
- 上传进度条
- 状态消息显示

#### 管理界面
- 文件列表显示
- 操作按钮（删除、重载）
- 文件信息展示
- 响应式设计

## API接口

### 文件上传
```
POST /upload
Content-Type: multipart/form-data

参数：
- file: 要上传的文件

响应：
{
  "success": true,
  "message": "成功上传 X 个文件",
  "files": [
    {
      "type": "model|source",
      "filename": "文件名"
    }
  ]
}
```

### 视频源管理
```
GET /sources/list - 获取视频源列表
DELETE /sources/del?name=文件名 - 删除视频源
```

### 模型管理
```
GET /models/list - 获取模型列表
DELETE /models/del?name=文件名 - 删除模型
POST /reloadModels - 重载模型列表
```

## 使用方法

### 1. 展开/折叠功能区域
- 点击"展开全部"按钮可以一次性展开所有上传和管理区域
- 当所有区域都已展开时，按钮会变为"折叠全部"，点击可折叠所有区域
- 或者点击各个区域的标题栏来单独展开/折叠
- 按钮文本会根据当前状态自动更新

### 2. 上传视频源
1. 展开"📤 上传视频源"区域
2. 点击"选择视频文件"按钮
3. 选择要上传的视频文件（支持多选）
4. 点击"上传视频"按钮
5. 等待上传完成，查看状态消息

### 3. 上传AI模型
1. 展开"📤 上传AI模型"区域
2. 点击"选择模型文件"按钮
3. 选择要上传的模型文件（支持多选）
4. 点击"上传模型"按钮
5. 等待上传完成，查看状态消息

### 4. 管理文件
1. 展开相应的管理区域查看文件列表
2. 点击"删除"按钮删除不需要的文件
3. 点击"刷新"按钮更新列表
4. 对于模型，可以点击"重载"按钮重新扫描模型目录

### 5. 模型切换
1. 在视频流运行时，从模型下拉列表中选择新模型
2. 系统会弹出确认对话框询问是否应用新模型
3. 选择"确认更换"会重新加载视频流应用新模型
4. 选择"取消"会恢复到原来的模型选择

### 6. 折叠功能区域
- 点击标题栏的箭头图标可以折叠区域
- 折叠状态会自动保存，下次访问时恢复

## 技术实现

### 后端改进
- 修改了`file_manager.py`，添加了`save_model()`和`del_model()`方法
- 更新了`streamer.py`中的文件上传处理逻辑
- 添加了文件类型自动识别功能
- 改进了API响应格式，统一使用JSON

### 前端改进
- 添加了文件上传界面组件
- 实现了上传进度显示
- 添加了文件管理列表
- 改进了错误处理和状态显示
- 添加了响应式设计

### 文件类型支持
- **视频源**：MP4, AVI, MOV, MKV, H264, PNG, JPG, JPEG
- **AI模型**：PT, PTH, ONNX, ENGINE

## 安全考虑

1. **文件类型验证**：后端严格验证文件扩展名
2. **文件大小限制**：建议在Web服务器配置中设置合理的文件大小限制
3. **路径安全**：使用安全的文件路径处理，防止路径遍历攻击
4. **权限控制**：确保上传目录有适当的读写权限

## 注意事项

1. 确保服务器有足够的存储空间
2. 大文件上传可能需要较长时间，请耐心等待
3. 删除操作不可恢复，请谨慎操作
4. 建议定期备份重要的模型和视频文件
5. 如果上传失败，请检查文件格式和大小是否符合要求
